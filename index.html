Real-world capture is slow and never covers every condition you need it to. Syntheta takes what you already shot, restores it for low light using NeuroDepth-T4 — a restoration model that works the way an event camera does, tracking per-pixel brightness changes instead of raw color — then multiplies each frame into several outputs: R2R mutation (Real2Robust — simulated weather, lighting, and sensor noise), FunctaGen re-synthesis (a neural model that renders new in-between views), and a clean passthrough baseline. Person labels are detected once and carried forward frame-for-frame onto every output, so nothing has to be re-labeled by hand.

Pipeline · seven stages

One input directory.
Two detection passes.

Person-detection runs exactly twice per run — once on the original frames (shared by Branches A and C), once on FunctaGen's generated frames (Branch B). Branch B never ships empty: if that second pass finds nobody, it falls back to the first pass's labels.

Label once

YOLOv8n-pose detects people in the original frames and builds a track set that Branches A and C reuse frame-for-frame — no re-labeling needed.

detection
FRAME02

NeuroDepth-T4 restoration

EventCore V8.1 restores low-light frames using simulated per-pixel brightness events, the way an event camera would. If restoration fails or comes out too dark, the original frame is used instead — logged as a fallback in the run's manifest.

restoration
FRAME03

Branch A — R2R mutation

Real2Robust (R2R) applies domain-gap mutations — simulated weather, lighting shifts, sensor noise — to the restored frames. Labels carry forward from stage 1, no re-detection needed.

synthetic
FRAME04

Branch C — passthrough

The clean, un-mutated baseline — restored frames copied through with the same carried-forward labels.

baseline
FRAME05

FunctaGen — neural in-between frames

An implicit neural representation (INR) — a small neural network trained to render a scene from any viewpoint — blends between two captured frames' learned latents (a "slerp," or spherical interpolation) to render new intermediate views.

synthesis
FRAME06

Branch B — fresh detection + R2R

A second YOLO pass runs on FunctaGen's generated frames at a lower confidence threshold, then R2R mutates the result. Zero detections falls back to stage 1's labels, so Branch B always ships labeled.
